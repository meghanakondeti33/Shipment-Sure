## 📌 Overview

**ShipmentSure** is an end-to-end Machine Learning application designed to predict whether a shipment will reach the customer **on time or not** based on shipment, product, and customer-related information.

The project transforms raw logistics data into a trained classification model and provides a user-friendly **Streamlit web application** through which users can enter shipment details and obtain a delivery prediction.

The project was developed as part of the **Infosys Springboard Internship**.

---

## 🎯 Problem Statement

Delayed shipments can negatively affect:

- Customer satisfaction
- Logistics efficiency
- Operational costs
- Delivery planning
- Business reputation

The objective of ShipmentSure is to use historical shipment data to predict the likelihood of a shipment being delivered on time.
